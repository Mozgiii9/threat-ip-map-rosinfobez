# CLAUDE.md — Демо «Тепловая карта вредоносных IP» (РосИнфоБез, вайб-кодинг live)

## Назначение
Этот проект собирается **вживую на сцене за ~10 минут** как демо вайб-кодинга для
аудитории C-level. Итог: интерактивная **SOC-панель — тепловая карта киберугроз на
карте мира**, развёрнутая на **TimeWeb Apps** и доступная по ссылке, которую зал
сканирует с **QR-кода**.

**Триггер:** когда пользователь пишет что-то вроде «Собери тепловую карту IP» /
«Запусти демо тепловой карты» — выполняй спецификацию ниже **без лишних уточнений**
(всё нужное здесь есть). Уточнения пользователя приоритетнее значений по умолчанию.

**Главные приоритеты, в порядке важности:**
1. **Надёжность на сцене** — должно гарантированно открыться и работать вживую.
2. **Скорость сборки** — уложиться примерно в 10 минут.
3. **Впечатляющий UI** — «вау» у нетехнической аудитории.

Минимум кода, который решает задачу. Никаких фич сверх описанных.

## Архитектура (соблюдай строго, ничего не добавляй)
**Всё работает в браузере на синтетических данных. Без бэкенда, без сети, без тайлов.**

- **Фронт:** ОДИН файл `static/index.html` — inline CSS + vanilla JavaScript.
  Без React, без сборщиков, без npm.
- **Карта мира:** **векторная**, через [D3](https://d3js.org/) (`d3.min.js`) +
  [topojson-client](https://github.com/topojson/topojson-client) поверх локального
  атласа мира TopoJSON (`world-110m.json`). **Никаких тайловых карт (Leaflet/CARTO/OSM).**
- **Тепло/угрозы:** неоновые точки-хотспоты поверх карты (SVG/canvas), размер и цвет
  по `severity` и `count`; ощущение «тепла» — через свечение/радиальные градиенты и
  скопление точек. Пульсация маркеров — CSS-анимация.
- **Бэкенд:** минимальный **FastAPI**, единственная задача — отдавать `static/`.
  В проде на TimeWeb Apps Python даже не запускается (статика). FastAPI — только для
  локального запуска.
- **Окружение:** менеджер пакетов **uv**, виртуальное `.venv`. Зависимости — только
  `fastapi` и `uvicorn`. (Для шага QR — ещё `qrcode[pil]`.)

> Почему так: тайловые карты тянут картинки с внешнего CDN (CARTO/OSM) — из РФ это
> ненадёжно и **ломает демо «серой картой»**. Векторный мир зашит локально → всё
> рендерится офлайн, ноль внешних запросов, и стилизованный тёмный мир даже **сильнее
> попадает в cyberpunk-эстетику**, чем уличные тайлы.

### ⚠️ Библиотеки и данные — только локально (vendoring), без CDN
На этапе сборки **скачай** в `static/vendor/`:
- `d3.min.js` (полный D3 или хотя бы d3-geo + d3-selection),
- `topojson-client.min.js`,
- `world-110m.json` — атлас мира TopoJSON (например, countries-110m из world-atlas).

Шрифты — системный моноширинный стек (`ui-monospace, SFMono-Regular, Menlo, monospace`)
для цифр/лога, **без Google Fonts CDN**. Никаких `<script>`/`<link>` на внешние CDN.

### Структура проекта
```
Threat IP Map/

  app/
```

порт из `PORT` (дефолт 8000), хост `0.0.0.0`.

## Данные — ТОЛЬКО синтетика, офлайн
- Сгенерируй правдоподобный датасет **60–100 точек**, **минимум 12–15 стран** по всему
  миру (для красивой картины), и положи в `static/data/threats.json`. Допустимо взять
  за основу `../Промпты для вайбкодинга/Тепловая карта IP/mock_threats.json`.
- **Никаких реальных threat-фидов и сетевых запросов при старте** — демо проходит офлайн.
- Геокодинг уже «выполнен»: `lat`/`lon` заданы прямо в данных, никаких внешних геокодеров.
- Схема каждой точки (соблюдать строго):
  ```js
  {
    ip: "203.0.113.45",        // string
    count: 1284,               // number — интенсивность (для размера/тепла)
    country: "Россия",         // string — название на русском
    countryCode: "RU",         // string — ISO alpha-2
    lat: 55.75, lon: 37.62,    // number
    attacks: 1284,             // number
    incidents: 17,             // number
    ports: [22, 3389, 445],    // number[]
    severity: "high"           // "low" | "medium" | "high" | "critical"
  }
  ```

## Функциональность

### Ядро (обязательно — проверить, что работает)
1. **Тёмная векторная карта мира** (D3 + локальный TopoJSON), проекция вроде
   `geoNaturalEarth1`/`geoMercator`, центр на весь мир. Без тайлов.
2. **Точки-угрозы** поверх карты по координатам, цвет/размер по `severity`/`count`,
   неоновое свечение; пульсация (CSS) для высоких severity.
3. **Клик по точке → попап с деталями:** IP, страна, число атак, инцидентов, целевые
   порты, severity. Без эмодзи/флагов в подписях.
4. **KPI-плашки сверху** с плавными count-up счётчиками: всего атак, уникальных IP,
   затронуто стран, критических инцидентов.
5. **Фильтры:** по **severity/категории угрозы** и по **threat-score** (порог `count`,
   ползунок). Карта и сводка пересчитываются.
6. **Сводка по странам:** Топ-5 стран по суммарным атакам — простой горизонтальный
   бар-чарт (можно на SVG/div, без внешних чарт-библиотек).
7. **Live Threat Log:** лента событий, обновляется по mock-таймеру (новое событие раз
   в 2–4 сек на основе данных): время, IP, страна, severity. Автоскролл, ограничение длины.

### Опционально (если осталось время — не в ущерб ядру)
- **Импорт IP-базы:** загрузка CSV/JSON через `<input type="file">`, парсинг и
  валидация по схеме на клиенте, добавление точек на карту (lat/lon берём готовые).
- **Мультивыбор стран** с «перелётом»/подсветкой региона.

## Дизайн (зал должен сказать «вау»)
Аудитория — руководители, не разработчики. Интерфейс **на русском**, тёмная тема,
широкий экран (проектор/сцена; адаптив не критичен). Единый бренд с презентацией и
с демо «Сравнение документов».

- **База бренда:** фон чёрный (`#0A0A0A`–`#141414`), основной акцент жёлтый
  (`#FFD400`/`#F5C518`), текст белый. KPI-цифры — крупные жёлтые.
- **Severity-шкала** (единая во всём — точки/лог/бары), поверх тёмного фона:
  `low` — cyan/зелёный, `medium` — жёлтый, `high` — оранжевый, `critical` — красный/magenta.
  Лёгкое неоновое свечение (`text-shadow`/`box-shadow`), моноширинные цифры и лог.
- Компоновка: карта по центру, KPI сверху, боковая панель со сводкой стран и live-логом.
- Без стоковых картинок, клипарта, эмодзи и флагов в подписях карты.

## Запуск локально
В `README.md` дать точные команды:
```bash
uv venv
uv sync
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```
Открыть `http://localhost:8000`. **Перед деплоем проверь локально** (желательно
браузерным e2e, как делали для демо 1): карта рисуется, точки кликаются, фильтры и
KPI считают, live-лог тикает, в консоли нет ошибок, **нет ни одного внешнего запроса**.

   `is_auto_deploy=false`, `envs={}`.
4. Дождаться выдачи URL вида `*.twc1.net`. **DNS поддомена публикуется на стороне

   резолвится в NXDOMAIN. Проверять можно через `--resolve hostname:443:<IP>`.

## QR-код для зала
После того как боевой `https://<...>.twc1.net` отдаёт страницу:
1. `uv add "qrcode[pil]"`.
2. Сгенерировать `qr.png` **локально** (не через онлайн-QR-сервисы):
   ```bash
   uv run python -c "import qrcode; qrcode.make('<URL>').save('qr.png')"
   ```
3. Открыть на весь экран: `open qr.png`. Продублировать URL текстом.
