# Тепловая карта вредоносных IP

Интерактивная SOC-панель: тепловая карта киберугроз на карте мира. Демо вайб-кодинга
для РосИнфоБез. Всё работает **в браузере** на синтетических данных, **офлайн** —
векторная карта (D3 + локальный TopoJSON), без тайлов и без CDN. Бэкенд только отдаёт
статику.

## Запуск локально
```bash
uv venv
uv sync
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```
Открыть http://localhost:8000

## Деплой (статика)
Всё приложение — папка `static/`. Разворачивается на TimeWeb Apps (frontend/static,
`index_dir=/static`, без сборки) из публичного git-репозитория.

## Данные
`static/data/threats.json` — синтетический датасет (100 точек, 25 стран). Реальные
threat-фиды не используются.
